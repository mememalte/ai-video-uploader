AI Video Uploader

AI Video Uploader is a desktop application for preparing and publishing educational video content to social media platforms.

About the application

The application helps creators manage educational videos, thumbnails, descriptions and publishing workflows.

Supported platforms include YouTube, TikTok and Instagram.

Social Media Publishing

The application allows users to connect their own social media accounts using the official authorization systems provided by each platform.

Users explicitly authorize the application before content is published to their accounts.

Privacy

The application does not request or store users' social media passwords. Account authorization is performed through the official OAuth authentication systems of the respective platforms.

Contact

For questions regarding the application, please contact the application owner.
